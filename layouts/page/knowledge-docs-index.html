Money Movement

The platform provides capability-based APIs for wallets, transfers, and compliance operations.

GET /api/v1/wallets

List wallets and balances across all currencies.

POST /api/v1/transfers/send

Initiate an outbound transfer with risk-tiered approval gate.

POST /api/v1/swap

Execute a currency swap with quoted FX rate and atomic settlement.
